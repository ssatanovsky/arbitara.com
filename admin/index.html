GitHub access token

Create a fine-grained token limited to this one repository.

  1. Open github.com/settings/personal-access-tokens/new
  2. Token name: arbitara-admin · Expiration: your choice
  3. Repository access → Only select repositories → ssatanovsky/arbitara.com
  4. Permissions → Repository permissions → Contents → Read and write
  5. Generate, copy the token (github_pat_…), and paste it below.
